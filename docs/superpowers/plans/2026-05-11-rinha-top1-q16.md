# Rinha Top1 Q16 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reach top1-level score by achieving `weighted_errors_E=0`, `http_errors=0`, and official p99 below `1.14ms`.

**Architecture:** Replace the final production detector with a q16/block-layout IVF index equivalent to the Go reference that scored `E=0`, then optimize the Zig runtime until p99 is below the current top1. The q16 path preserves the official `round4` feature grid exactly (`scale=10000`), uses 8-vector dim-major blocks, and runs full bbox-pruned fallback only for borderline `fraud_count in {2,3}`.

**Tech Stack:** Zig 0.16, mmap, flat binary index, Docker Compose, GitHub Actions k6 diagnostic, official Rinha preview.

---

## Current Evidence

- H14 official: p99 `1.19ms`, FP `554`, FN `592`, `E=2330`, score `3280.20`.
- H15 official: p99 `1.63ms`, FP `54`, FN `60`, `E=234`, score `4439.08`.
- H15 diagnostic: brute force int8 fallback on all borderline cases did not change `E=234`.
- Conclusion: remaining errors are not missed clusters under int8; they are precision loss from int8. Top1 requires q16/float-like distances.

- [ ] **Step 1: Add q16 quantization**

Add:

```zig
pub fn quantize16(v: f32) i16 {
    const clamped = if (v < -1) -1 else if (v > 1) 1 else v;
    if (clamped >= 0) return @intFromFloat(clamped * 10000.0 + 0.5);
    return @intFromFloat(clamped * 10000.0 - 0.5);
}
```
